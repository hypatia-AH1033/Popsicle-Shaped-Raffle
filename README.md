# Popsicle-Shaped-Raffle
A browser-based lottery tool modeled after retro “prize-winning ice cream sticks,” featuring realistic adjustment of remaining tickets. Set the number of tickets and the distribution of winning tickets for 1st through 5th prizes, then let your guests take their turns! Perfect for home parties or team-building retreats.
------------------------------------------------------------------------------------------------------
# 🍦 仕様書：昭和レトロ アイス棒くじ引き（Ver1.1）

## 1. 概要

昭和レトロな「当たり付きアイスの棒」をモチーフにした、ブラウザで動くリアル残数調整型のくじ引きツール。

## 2. システム構成

* **動作環境**: ブラウザ全般（PC / スマホ / タブレット対応）
* **ファイル構成**: 単一ファイル構成 (`index.html` 1ファイル / 外部ライブラリ不使用)
* **使用技術**: HTML5, CSS3, JavaScript (Vanilla JS)

---

## 3. 機能要件

### 3.1. 設定機能 (Config)

* **モード選択**:
* **本数指定**: 各等級の「本数」を直接指定。
* **確率(%)指定**: 各等級の「当選確率」を指定（自動で本数換算）。


* **母数設定**: くじを引く全体の人数（1〜1000人）を設定可能。
* **等級設定（1等〜5等）**:
* 1等〜4等：個別で本数または割合を設定可能。
* 5等（ハズレ）：残りの人数（本数）を自動計算・補填。


* **バリデーション（入力チェック）**:
* 1〜4等の合計が母数（または100%）を超えた場合、エラーメッセージを表示して開始ボタンを非活性化。



### 3.2. くじ引きプレイ機能 (Play Area)

* **リアルタイム残数表示**:
* 「残りくじ数 / 全体数」を画面上部にリアルタイム表示（母数減少型）。


* **アイス棒アニメーション演出**:
* クリック/タップでアイス棒がせり上がり、先端に等級テキストが文字浮き出し表示。


* **手動シャッフル機能（🔀）**:
* 残りくじの配列をランダムに再シャッフル（フィッシャー–イェーツアルゴリズム）。
* シャッフル時に棒が左右に揺れるシェイクアニメーションとアラートを表示。


* **引いた棒の履歴表示（履歴スタック）**:
* 引いた結果を画面下部に色分けされたミニタグとして自動追加（自動スクロール付き）。
